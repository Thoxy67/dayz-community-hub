# dayz-community-hub-git

Arch package for [DayZ Community Hub](https://git.thoxy.xyz/thoxy/dayz-community-hub),
a DayZ launcher: server browser, mod manager and offline mode. It builds the
latest `master` from source.

## Install

With an AUR helper pointed at this repository, or by hand:

```sh
git clone https://git.thoxy.xyz/AUR/dayz-community-hub-git.git
cd dayz-community-hub-git
makepkg -si
```

Rebuild to update (`makepkg -si` again, or your helper's devel update): the
version is `<app version>.r<commit count>.g<commit>` and moves with every
commit on `master`.

This repository is generated by `make aur` in the source repository, from
`packaging/aur/PKGBUILD.in`; changes belong there.
